# 找肥丸

内置六课推理教学：已知位置排除、唯一候选、颜色锁行、行锁颜色、共同禁区、两列占两色。新玩家看完操作说明后进入，可跳过；选关页“推理教学”可重看。固定局部棋盘、已知叉号、高亮线索、可选提示；错误不扣血，完成当前推理即可下一课。教学期间暂停底层普通关计时，不改变正式进度。

一个纯前端逻辑小游戏，共30关：5×5至12×12每种3关不限时，第25～27关为300秒限时12×12，第28～30关为120秒限时12×12。每行、每列、每种颜色各有一只肥丸，肥丸之间不能相邻（含斜角）。

单击打叉或取消，拖动连续打叉，双击确认肥丸。猜错扣一滴血并锁定格子，每局两滴血。支持独立音效与震动开关；震动需浏览器和设备支持。

固定关卡、每日挑战和极限挑战统一使用本地 balanced-v6 生成器。先在固定尝试与节点预算内构造均衡分区；未成功则对已验证模板做有限边界变异，始终保留完整逻辑可解的有效题，最终可返回模板保底。各区域面积限制为 max(2, floor(尺寸×0.4)) 至 ceil(尺寸×1.8)，不再使用大片背景区域算法。模板变体不代表每次完全原创，尤其12阶基础答案排列仍较少。

这批固定关卡从480张候选中选出30张，按尺寸升序；同尺寸内按最高推理规则层级、加权推理步数排序。确定位置计1、共同排除计3、成对约束计6，难度仅为程序估计，未经过玩家校准。原关卡编号、解锁和通关进度保留，棋盘内容已替换。每日种子与完成记录使用新算法命名空间，历史记录未删除。

项目早期参考 [gitars/queens-generator](https://github.com/gitars/queens-generator)，上游许可证保留于 THIRD_PARTY_LICENSE.txt。该许可证不覆盖角色美术；角色形象权利归原权利人所有。

每关的 timeLimitSeconds 默认为0，不显示倒计时；大于0则进入关卡立即计时，归零失败，切后台或进入选关不暂停，重来恢复完整时间。
